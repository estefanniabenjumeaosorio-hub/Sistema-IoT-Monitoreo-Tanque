
# Sistema IoT de Monitoreo de Nivel de Tanque

## Integrantes
- Estefannia Benjumea Osorio
- Victor Gomez
- Johan Andres Isaza

## Descripción
Proyecto desarrollado para monitorear el nivel de un tanque mediante un sensor ultrasónico HC-SR04 conectado a un ESP32.

## Tecnologías utilizadas
- ESP32
- Sensor HC-SR04
- ThingSpeak
- Arduino IDE
